# Vox AI Relay 0.8.0

Vox AI Relay is the new name of the Android voice communicator previously distributed as OpenClaw Android.

## Highlights

- One application for OpenClaw Gateway and Hermes Agent.
- Persistent backend selection.
- Streaming text and sentence-level Android TTS.
- On-device-first Android speech recognition.
- Real interruption: stop only, or stop and immediately listen.
- Hermes conversation continuity, tool activity, Vision, PDF page rendering, and `ntfy` push.
- OpenClaw history, attachments, pairing, notifications, and reconnection.
- New adaptive launcher icon and complete English/Polish GitHub documentation.

## Upgrade note

The application ID and signing lineage are intentionally unchanged. Install 0.8.0 over the previous build to retain settings and credentials, provided the APK is signed with the same key.

## Installation

1. Download `Vox-AI-Relay-0.8.0-debug.apk`.
2. Allow installation from the browser or file manager used to open the APK.
3. Install over the existing application or install fresh.
4. Open Settings and configure OpenClaw, Hermes, or both.

## Verification

Compare the downloaded APK with the published SHA-256 checksum before installation.
