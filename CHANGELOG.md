# Changelog

## 0.8.0 — 2026-11-10

- Renamed the application to Vox AI Relay.
- Added a new adaptive Android launcher icon and legacy fallback icon.
- Documented OpenClaw, Hermes, Android voice, Vision, PDF, interruption, privacy, and build functionality.
- Fixed response interruption semantics: stop means stop only; microphone means stop and listen.
- Preserved the existing Android application ID for upgrade compatibility.

## 0.7.1 — 2026-11-10

- Added real one-action voice barge-in for Hermes and OpenClaw.
- Made the square stop button terminate backend generation as well as TTS.

## 0.7.0 — 2026-11-09

- Added durable Hermes transcript continuity and server-side history restoration.
- Separated Hermes transcript identity from long-term-memory scope.

## 0.6.9 — 2026-11-09

- Added Hermes Vision for photographs and locally rendered PDF pages.
